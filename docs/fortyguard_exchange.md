This file is generated by `engine/scripts/verify_api.py`, which makes live calls
and writes the verbatim pair here with the API key redacted.

To generate the real exchange:

```bash
cd engine
FORTYGUARD_API_KEY=... .venv/bin/python scripts/verify_api.py
```

offsets the heatmap yields, and reports the credit spend.
